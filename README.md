# Weight Tracker - Приложение для отслеживания веса и параметров тела

Мобильное веб-приложение для семейного использования. Позволяет отслеживать вес и другие параметры тела, устанавливать цели и визуализировать прогресс.

## 🚀 Быстрый старт

### 1. Настройка Supabase

1. Создайте проект на [supabase.com](https://supabase.com) (бесплатный тариф)
2. Перейдите в SQL Editor и выполните SQL из файла `supabase-schema.sql`
3. В разделе Authentication → Settings:
   - Включите провайдер Email/Password
   - Отключите "Confirm email" для упрощения
4. В Settings → API скопируйте URL и anon key

### 2. Настройка проекта

```bash
# Установка зависимостей
npm install

# Создание файла окружения
cp .env.example .env
